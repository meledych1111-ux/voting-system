# 🗳️ Система голосования

Полнофункциональная система для создания опросов и проведения голосований с подтверждением по email.

## 🚀 Быстрый старт

1. **Создайте репозиторий** на GitHub
2. **Загрузите все файлы** в репозиторий
3. **Подключите репозиторий** в Vercel
4. **Добавьте переменные окружения** в настройках Vercel

## 🔑 Переменные окружения

В настройках Vercel добавьте:

- `EMAILJS_PUBLIC_KEY` = ваш_public_key_из_emailjs
- `EMAILJS_SERVICE_ID` = ваш_service_id_из_emailjs  
- `EMAILJS_TEMPLATE_ID` = ваш_template_id_из_emailjs

## 📧 Настройка EmailJS

1. Создайте шаблоны в EmailJS для:
   - Регистрации администратора
   - Восстановления пароля

2. В шаблонах используйте переменные:
   - `{{to_name}}` - имя получателя
   - `{{to_email}}` - email получателя
   - `{{confirmation_code}}` - код подтверждения
   - `{{new_password}}` - новый пароль (для восстановления)
   - `{{type}}` - тип сообщения

## ✨ Функциональность

- ✅ Регистрация администраторов с подтверждением по email
- ✅ Восстановление пароля администратора
- ✅ Создание и управление опросами
- ✅ Участие в голосовании
- ✅ Просмотр результатов в реальном времени
- ✅ Экспорт данных
- ✅ Адаптивный дизайн
